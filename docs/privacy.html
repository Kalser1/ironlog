LiftBook

Политика конфиденциальности

Дата обновления: 17 ноября 2026 года

1. Общие положения

LiftBook — офлайн-приложение для ведения дневника силовых тренировок. Приложение не требует регистрации и не создаёт аккаунт. У приложения нет разрешения на доступ в интернет, поэтому оно не отправляет данные на серверы разработчика или третьих лиц.

2. Какие данные хранятся на устройстве

Приложение сохраняет только данные, которые пользователь вводит сам:

  • тренировки: упражнения, подходы, веса, повторы, заметки, даты и объём;
  • программы и рутины, включая суперсеты;
  • личные упражнения: название, группа мышц, оборудование, уровень сложности и описание техники;
  • настройки: тема оформления, акцентный цвет, параметры таймеров отдыха и режим отправки программ.

Эти данные хранятся локально в хранилище приложения на устройстве. Разработчик не имеет к ним доступа.

3. Сбор и передача данных

Приложение не собирает, не продаёт и не передаёт персональные данные. В нём нет рекламы, аналитических и crash-сервисов. Приложение не запрашивает доступ к местоположению, контактам, камере, микрофону, фотографиям, файлам, SMS, звонкам или рекламному идентификатору.

4. Разрешения

Приложение запрашивает только разрешения, необходимые для таймера отдыха:

  • уведомления (POST_NOTIFICATIONS) — чтобы показать уведомление об окончании отдыха;
  • точные будильники (SCHEDULE_EXACT_ALARM) — чтобы уведомление сработало вовремя даже при выключенном экране; без этого доступа таймер работает с возможной задержкой;
  • вибрация (VIBRATE) — для вибрации уведомления.

Эти разрешения не используются для сбора данных.

5. Обмен программами и тренировками

Пользователь может самостоятельно отправить программу или тренировку через системное меню «Поделиться» либо скопировать код в буфер обмена. Действие выполняется только по команде пользователя и через выбранное им приложение. Веса завершённых тренировок в отправляемые данные не включаются. Разработчик не получает копию отправленных данных.

6. Хранение и удаление

Данные хранятся на устройстве до удаления приложения или очистки его данных. При удалении приложения данные удаляются вместе с ним. Серверной копии и аккаунта нет, поэтому отдельный запрос на удаление данных не требуется. Средства резервного копирования Android могут сохранять данные в аккаунте пользователя в соответствии с настройками его устройства; разработчик не имеет к этой копии доступа.
